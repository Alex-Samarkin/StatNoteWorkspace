# Семантика переменных

Статус: DRAFT 0.1. Критический раздел; финализируется в M3.

## Основное правило

Переменная, созданная присваиванием без модификатора, **локальна для ячейки**.
После исполнения ячейки локальные имена уничтожаются.

## Объявление глобальных

```
global пациенты <- загрузить_csv("data.csv");
пациенты <<- загрузить_csv("data.csv");
загрузить_csv("data.csv") ->> пациенты;
```

Массовый экспорт атрибутом ячейки:

```
[Экспорт(пациенты, средний_возраст)]
{
    пациенты <- загрузить_csv("data.csv");
    средний_возраст <- среднее(пациенты.возраст);
    порог <- 50;          (* останется локальной *)
}
```

## Алгоритм разрешения имени

1. Локальная область текущей ячейки.
2. Вложенные области внутри ячейки, от внутренней к внешней.
3. Глобальный контекст `Globals`.
4. Определения подвала и подключённых пакетов.
5. Иначе — ошибка SN0202 с указанием ячейки и строки.

Квалификатор `global::имя` начинает поиск с шага 3, минуя локальные области.

## Затенение

Локальное имя, совпадающее с глобальным, скрывает глобальное.
Выдаётся предупреждение SN0201 с обоими типами и рекомендацией.
При `@strict_shadowing true` предупреждение становится ошибкой.

## Режим совместимости

`@variable_scope r_style` делает переменные глобальными по умолчанию.
Предназначен для миграции существующих R-сценариев; выдаёт предупреждения
о потенциально опасных переопределениях.

## Влияние на граф зависимостей

Чтения ячейки — имена, разрешённые на шагах 3 и 4.
Записи ячейки — имена, объявленные глобальными.
Локальные имена в граф не попадают. Цикл между ячейками — ошибка SN0203.

## Условное определение

Если глобальная переменная создаётся внутри ветвления, она помечается как
условно определённая. Чтение без проверки даёт предупреждение SN0204.
