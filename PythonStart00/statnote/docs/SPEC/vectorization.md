# Векторизация

Статус: DRAFT 0.1. Финализируется в M4.

## Синтаксис

```
y <- f.(x);                  (* поэлементное применение функции *)
z <- x .+ y;                 (* поэлементный оператор *)
w <- (x .+ y) .* 2 .- 5;     (* цепочка со сплавлением *)
v <- @. (x + y) * 2 - 5;     (* broadcast всего выражения *)
```

## Разбор точечных форм

| Форма | Значение |
|---|---|
| `obj.field` | доступ к объявленному члену |
| `obj$field` | доступ к динамическому словарю |
| `f.(args)` | broadcast вызова функции |
| `x .+ y` | broadcast оператора |

Разрешается lookahead: точка, за которой следует открывающая скобка, — broadcast;
за которой следует идентификатор — доступ к члену.

## Правила размерностей

Скаляр растягивается до формы коллекции. Вектор применяется построчно к матрице.
Несовместимые формы — ошибка SN0501 с описанием обеих размерностей.

## Сплавление

Цепочка точечных операций компилируется в один проход без промежуточных массивов.
Барьерами сплавления служат: функции без атрибута чистоты, обращения к внешним
средам, операции с побочными эффектами.

Функция пакета с атрибутом `[StatPure]` барьером не является — сплавление работает
через границы библиотек.

## Пропущенные значения

NA распространяется поэлементно. Агрегатные функции принимают политику NA
явно; значение по умолчанию — открытый вопрос OQ-06.

## Требования к тестам

Аллокационный тест: цепочка из трёх точечных операций над вектором длины 1e6
не должна создавать промежуточные массивы. Проверяется счётчиком аллокаций,
а не только временем выполнения.
