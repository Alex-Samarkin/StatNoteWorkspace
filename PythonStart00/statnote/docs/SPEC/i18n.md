# Билингвальность

Статус: DRAFT 0.1. Финализируется в M2.

## Директива

```
@language ru;         (* только русские ключевые слова *)
@language en;         (* только английские *)
@language ru, en;     (* оба словаря одновременно, по умолчанию *)
```

Директива располагается в преамбуле до любого кода. Смена языка в середине
документа запрещена.

## Область действия

Директива влияет только на ключевые слова, имена типов и системные сообщения.
Пользовательские идентификаторы свободны и допускают Unicode независимо от режима.

## Формат словаря

Файлы `.lang` в YAML. Секции: `keywords`, `types`, `literals`, `messages`.
Словарь отображает каноническое английское имя в локализованное.

## Эквивалентность

Документ на русском и его дословный перевод на английский обязаны давать
идентичное абстрактное синтаксическое дерево. Это врата F1 и golden-тест M2.

## Сообщения

Все диагностики форматируются по шаблону из секции `messages` активного словаря.
Код ошибки не локализуется. Подсказки и рекомендации локализуются.

## Расширение

Добавление языка — новый файл `.lang` без изменения грамматики. Парсер получает
таблицу ключевых слов на этапе инициализации.
