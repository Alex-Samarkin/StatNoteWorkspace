# Классы и объекты

Статус: DRAFT 0.1. Финализируется в M4 и M5.

## Два уровня

Уровень 1 — объявленная структура класса: поля, свойства, методы. Доступ через точку.
Уровень 2 — динамический словарь экземпляра. Доступ через доллар.

```
класс Пациент {
    открытый строка ид;
    открытый целое возраст;
    открытый вещ вес;
    открытый вещ рост;

    открытый вещ имт {
        получить { вернуть вес / (рост * рост); }
    }
}

p <- создать Пациент();
p.возраст <- 52;              (* статическое поле *)
p$диагноз <- "Гипертония";    (* динамическое поле *)
```

## Правила

- Обращение через точку к необъявленному члену — ошибка SN0401 на этапе компиляции.
- Запись через доллар в имя, занятое статическим членом — ошибка SN0402 с подсказкой
  использовать точку.
- Динамические методы допустимы: `p$оценка_риска <- функция() { ... };`
- Наследование сохраняет оба уровня; динамический словарь не наследуется от родителя
  как содержимое, но создаётся у каждого экземпляра.

## Режимы класса

`[Strict]` запрещает динамический словарь вовсе. `[Dynamic]` разрешает; по умолчанию.

## Интроспекция

| Функция | Возвращает |
|---|---|
| `inspect(obj)` | дерево обоих уровней с типами и значениями |
| `fields(obj)` | все имена полей обоих уровней |
| `static_fields(obj)` | только объявленные поля |
| `dynamic_fields(obj)` | только ключи словаря |
| `methods(obj)` | объявленные методы |
| `has_field(obj, name)` | наличие поля на любом уровне |
| `field_type(obj, name)` | тип поля |
| `origin(fn)` | пакет, версия, файл исходника, хеш |

## Коллекции

Векторизованный доступ к полям: `patients.возраст` и `patients$группа_риска`
возвращают векторы значений по всем элементам.

## Сериализация

Раздельная: только статика, только динамика, полная с двумя разделами.
Формат по умолчанию JSON; для таблиц — Arrow.
