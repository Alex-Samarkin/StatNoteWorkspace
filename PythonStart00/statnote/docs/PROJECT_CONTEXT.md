## Девять неизменных решений

1. Транспиляция AST в C#, исполнение через Roslyn; пакетно — NativeAOT.
2. Переменные локальны по умолчанию; глобальные через `global`, `[Экспорт(...)]`, `<<-`;
   затенение с предупреждением; `global::` для явного доступа.
3. Объекты двухуровневые: `.` — объявленные члены, `$` — динамический словарь.
4. Присваивания `<-` и `->`; broadcast `f.(x)`, `.+` с fusion; `@.` для выражения.
5. Билингвальность через словари `.lang`, директива `@language` в преамбуле.
6. Невидимые преамбула и подвал; реактивность сверху вниз через граф reads/writes.
7. Внешние среды конфигурируются в преамбуле `@configure`; marshalling с NA; Arrow.
8. UI на Avalonia: пять вкладок; режимы отображения ячеек.
9. Нативные пакеты на C# в исходниках; MVS и замок; реестр git plus proxy; ALC;
   `[StatPure]` как условие cross-package fusion.
