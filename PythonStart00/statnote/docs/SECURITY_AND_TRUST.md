# Безопасность и доверие

## Модель угроз

Пакет распространяется исходниками C# и компилируется на машине пользователя.
Это означает произвольный код с полными правами процесса. Изоляция CLR
не является песочницей.

## Уровни доверия

| Уровень | Источник | Поведение по умолчанию |
|---|---|---|
| Курируемый | официальный реестр, рецензированный запрос | разрешён |
| Подписанный | известный издатель, проверенная подпись | разрешён с уведомлением |
| Прямой git | произвольный репозиторий | требует явного подтверждения |
| Неизвестный | без записи в журнале сумм | запрещён |

## Механизмы

- Журнал контрольных сумм: несовпадение прерывает restore с ошибкой SN0601.
- Подписи записей реестра проверяются при обновлении метаданных.
- `pkg audit` выполняет анализ лицензий и статический поиск опасных API:
  файловая запись вне рабочей области, сеть, запуск процессов, рефлексия
  над внутренними типами runtime.
- Отзыв версии скрывает её из разрешения, но не удаляет: существующие замки
  продолжают работать, что сохраняет воспроизводимость прошлых публикаций.

## Изоляция

Открытый вопрос OQ-05: ограничиться статическим анализатором или выносить
недоверенные пакеты в отдельный процесс с ограниченным каналом обмена.
До решения недоверенные пакеты запрещены по умолчанию.

## Приватные зеркала

Организация может держать внутреннее зеркало реестра с методическими пакетами.
Переключение в `@configure`. Зеркало наследует журнал сумм upstream.

## Офлайн

Каталог `vendor/` содержит полные исходники зависимостей и коммитится в git.
Restore без сети обязан давать тот же результат, что и сетевой.
