# StatNote

Язык статистических вычислений и среда научного литерного программирования.
Рабочее название; подлежит уточнению (см. `docs/OPEN_QUESTIONS.md`).

## Статус

Предпроектная документация. Реализация не начата. Текущая фаза — **F0**.

## Суть

Документ `.smd` объединяет текст, формулы, расчёты и графики. Невидимые преамбула
и подвал задают окружение и инструментарий; видимые ячейки реактивны сверху вниз.
Один источник порождает PDF, HTML и PPTX.

Ключевые решения: транспиляция в C# на .NET 10; переменные локальны по умолчанию;
двухуровневые объекты (`.` статика, `$` динамика); broadcast с fusion; билингвальность
ru/en; нативные пакеты на C# в исходных кодах.
