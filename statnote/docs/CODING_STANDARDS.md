# Стандарты кода

## Именование

Типы, методы, свойства — PascalCase. Параметры и локальные — camelCase.
Приватные поля — с префиксом подчёркивания. Константы — PascalCase.
Имена говорящие; заглушки вида `temp`, `data2`, `None` запрещены.
Терминология — из `GLOSSARY.md`, английская колонка.

## Оформление

Файловые пространства имён. Nullable включён. Директивы System первыми.
Форматирование по `.editorconfig`. Строки пользовательских сообщений —
только через словарь локализации, не литералами.

## Документация

Каждый публичный член несёт XML-документацию с описанием назначения,
параметров, возвращаемого значения и исключений. Комментарии в теле
поясняют причину решения, а не пересказывают код.

## Ошибки

Исключения для нарушений контрактов; результат-объект для ожидаемых
неудач операций. Пользовательская диагностика — только через реестр кодов
`SPEC/diagnostics.md` с указанием ячейки и позиции.

## Асинхронность

Методы ввода-вывода асинхронны, суффикс Async, CancellationToken последним
параметром. Блокирующие вызовы в UI-слое запрещены.

## Заглушки

`NotImplementedException` допускается только с комментарием TODO и номером
модуля.Such заглушки собираются в отчёт CI.

## Тесты

Имя теста: `Method_Scenario_ExpectedResult`. Один тест — одно утверждение
о поведении. Arrange, Act, Raise разделены пустыми строками.

## Запреты

Магические строки и числа без именованных констант. Скрытые глобальные
состояния. Обращение к внешним средам из модулей Core и Parser.
