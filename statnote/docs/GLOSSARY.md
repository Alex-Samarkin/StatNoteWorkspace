# GLOSSARY

Единая терминология обязательна для кода, документации и сообщений.

| Русский | English | Определение |
|---|---|---|
| преамбула | preamble | Невидимый блок настройки окружения, исполняется первым |
| подвал | footer | Невидимый блок определений без побочных эффектов |
| ячейка | cell | Единица документа: разметка или расчёт |
| расчётная ячейка | compute cell | Ячейка, порождает результат и пишет переменные |
| реактивность | reactivity | Автоматический пересчёт зависимых ячеек |
| граф зависимостей | dependency graph | Отношение reads/writes между ячейками |
| устаревшая ячейка | stale cell | Ячейка, чьи входы изменились после исполнения |
| затенение | shadowing | Локальное имя скрывает глобальное |
| экспорт | export | Объявление переменной глобальной |
| статический член | static member | Объявленный в классе член, доступ через точку |
| динамический словарь | dynamic dictionary | Словарь экземпляра, доступ через доллар |
| broadcast | broadcast | Поэлементное применение операции к коллекции |
| сплавление | fusion | Объединение векторных операций в один проход |
| чистая функция | pure function | Функция без побочных эффектов, допускается в fusion |
| пакет | package | Комплект функций и типов на C# в исходниках |
| мультипакет | meta package | Пакет без кода, только зависимости и exports |
| реестр | registry | Git-репозиторий метаданных пакетов |
| замок | lock file | Фиксация версий и контентных хешей |
| MVS | minimal version selection | Выбор минимальной совместимой версии |
| вендоринг | vendoring | Офлайн-копия исходников зависимостей |
| ALC | AssemblyLoadContext | Изолированный контекст загрузки сборки |
| marshalling | marshalling | Преобразование типов между средами |
| транспиляция | transpilation | Перевод исходного кода в C# |
| golden-тест | golden test | Сравнение с эталонным артефактом |
| врата | gate | Условие перехода к следующей фазе |
| ADR | architecture decision record | Запись архитектурного решения |
| контекстный пакет | context bundle | Набор файлов для входа в сессию |

## Правило именования

Идентификаторы в коде — английские, из этого словаря. Пользовательские сообщения
и документация — билингвальные. Русские идентификаторы допустимы только в примерах
и учебных материалах.
