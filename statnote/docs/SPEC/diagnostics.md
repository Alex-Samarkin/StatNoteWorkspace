# Диагностика

Статус: DRAFT 0.1. Реестр ведётся с M1.

## Формат сообщения

```
[SN0201] Предупреждение: локальная переменная 'пациенты' затеняет глобальную
  --> ячейка 3, строка 7, столбец 5
  глобальная: DataFrame, объявлена в ячейке 1
  локальная:  DataFrame
  подсказка: переименуйте локальную переменную или используйте global::пациенты
```

Код не локализуется. Текст, подсказка и уровни серьёзности локализуются
через секцию `messages` активного словаря.

## Диапазоны кодов

| Диапазон | Область |
|---|---|
| SN0001–SN0099 | лексика |
| SN0100–SN0199 | синтаксис |
| SN0200–SN0299 | области видимости и зависимости |
| SN0300–SN0399 | типы |
| SN0400–SN0499 | классы и объекты |
| SN0500–SN0599 | векторизация |
| SN0600–SN0699 | пакеты и реестр |
| SN0700–SN0799 | внешние среды |
| SN0800–SN0899 | экспорт |
| SN0900–SN0999 | исполнение |

## Начальные коды

| Код | Серьёзность | Значение |
|---|---|---|
| SN0201 | предупреждение | затенение глобальной переменной |
| SN0202 | ошибка | имя не разрешено |
| SN0203 | ошибка | циклическая зависимость ячеек |
| SN0204 | предупреждение | чтение условно определённой переменной |
| SN0401 | ошибка | необъявленный член через точку |
| SN0402 | ошибка | динамическое поле конфликтует со статическим |
| SN0501 | ошибка | несовместимые размерности broadcast |
| SN0601 | ошибка | несовпадение контрольной суммы пакета |
| SN0602 | ошибка | несовместимая мажорная версия SDK |

## Совместимость с ранними черновиками

В ранних документах предупреждение о затенении обозначалось как SN001.
Канонический код — SN0201; SN001 сохраняется как алиас до версии 1.0.

## Правило добавления

Новый код резервируется в этом файле до реализации. Повторное использование
кода запрещено. Удаление кода запрещено; допускается пометка `deprecated`.
