# Формат документа .smd

Статус: DRAFT 0.1. Финализируется в M2.

## Общие положения

Кодировка UTF-8 без BOM. Переносы строк LF. Расширение `.smd`.
Документ — текстовый файл, пригодный для версионирования в git.

## Порядок секций

1. Директивы (`@language`, `@variable_scope`, `@strict_shadowing`).
2. Преамбула `[Преамбула]` или `[Preamble]` — ровно одна.
3. Ячейки: разметка и расчёты в произвольном чередовании.
4. Подвал `[Подвал]` или `[Footer]` — ровно один, физически в конце файла.

Подвал известен парсеру до исполнения, поэтому его определения доступны всем ячейкам.

## Преамбула

Содержит `@configure`, `@packages`, `using`, глобальные настройки, загрузку данных.
Допускает побочные эффекты. В экспорт не попадает никогда.

## Подвал

Содержит определения функций, классов, констант. Побочные эффекты запрещены;
проверяется анализатором в M3. В экспорт не попадает никогда.

## Ячейки

Расчётная ячейка — блок в фигурных скобках с необязательными атрибутами.
Ячейка разметки — Markdown с интерполяцией `{выражение}` и формулами LaTeX.

## Атрибуты ячейки

| Атрибут | Английский alias | Значение |
|---|---|---|
| `[Вычисление(истина)]` | `[Eval(true)]` | исполнять ли ячейку |
| `[Эхо(ложь)]` | `[Echo(false)]` | показывать ли исходный код |
| `[Видимость(код: ложь, результат: истина)]` | `[Visibility(...)]` | режим отображения |
| `[Экспорт(a, b)]` | `[Export(a, b)]` | какие переменные становятся глобальными |
| `[ПодписьРис("...")]` | `[FigCap("...")]` | подпись к графику |
| `[РежимОтображения("снизу")]` | `[DisplayMode("bottom")]` | локальный режим |

## Режимы видимости

`visible`, `hide_code`, `hide_output`, `hide_both`.
Режим `hide_both` исполняется, но в документе отсутствует полностью.

## Интерполяция

В тексте разметки `{выражение}` вычисляется в контексте ячейки, следующей сверху.
Форматирование через `:F1`, `:P2` и подобные спецификаторы.

## Исполнение

Интерактив: ячейки по требованию, реактивный пересчёт зависимых.
Пакет: чистое окружение, строго сверху вниз, детерминированный результат.
Результаты обоих режимов обязаны совпадать — это критерий приёмки.
